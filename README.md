# Документация проекта: Spamkilla 2.0

Telegram-бот для автоматической модерации спама в каналах и привязанных группах обсуждений на базе локальной языковой модели и асинхронного стека Python.

---

## 1. Стек технологий

* **Язык:** Python 3.11+
* **Фреймворк Telegram API:** `aiogram 3.x` (полностью асинхронный поллинг)
* **База данных и ORM:** PostgreSQL, `SQLAlchemy 2.x` (Async Engine), `asyncpg`
* **ML / Классификация:** Hugging Face `transformers`, PyTorch (CPU инференс, модель `corall88/russian_spam_detector`)
* **Конфигурация:** `python-dotenv`

## 4. Схема базы данных

### Таблица `bans`

Логирование фактов выявления спама и применения санкций:

* `id` (`Integer`, Primary Key, autoincrement) — идентификатор записи.
* `user_id` (`BigInteger`) — Telegram ID спамера.
* `message` (`Text` / `String`) — исходный текст спам-сообщения.
* `created_at` (`DateTime`) — временная метка фиксации нарушения.

### Таблица `whitelist`

Список доверенных пользователей, сообщения которых не проходят проверку:

* `id` (`Integer`, Primary Key, autoincrement) — идентификатор записи.
* `user_id` (`BigInteger`, Unique) — Telegram ID пользователя.
* `added_by` (`BigInteger`) — ID администратора, добавившего запись.

## 5. Алгоритм работы пайплайна модерации

```text
[Новое сообщение в канале/комментариях]
                  │
                  ▼
         [Проверка Whitelist] ──(В белом списке)──> [Пропуск сообщения]
                  │
                  ▼ (Не в белом списке)
       [Фильтр минимальной длины] ──(< 4 символов без ссылок)──> [Пропуск]
                  │
                  ▼
      [Инференс ML-модели в asyncio.to_thread]
                  │
        ┌─────────┴─────────┐
        ▼                   ▼
    [Не спам]            [Спам]
        │                   │
    [Пропуск]       [Проверка BOT_MODE]
                            │
               ┌────────────┴────────────┐
               ▼                         ▼
         [Режим: test]            [Режим: normal]
               │                         │
      [Алерт в админ-чат]       [1. Удаление сообщения]
     [Кнопки: Бан/Пропуск]      [2. Блокировка в чате]
                                [3. Запись в таблицу bans]
                                [4. Отчет в админ-чат]

```

---

## 6. Режимы работы (`BOT_MODE`)

Переключение режимов осуществляется глобальной переменной в памяти (или командами администратора):

1. **`normal`:**
* Сообщение со спамом удаляется немедленно.
* Нарушитель банится в чате через `bot.ban_chat_member`.
* Текст сообщения сохраняется в БД.
* В админ-чат отправляется уведомление об успешном устранении спама.


2. **`test` (Режим проверки и сбора данных):**
* Сообщение в чате не удаляется.
* В админ-чат приходит сообщение с текстом спама и Inline-кнопками: **«Забанить»** / **«Пропустить»**.
